# Diabetes Prediction System (Machine Learning App)

An interactive machine learning web application built with Streamlit that predicts the likelihood of diabetes based on patient medical data. The model uses a trained Support Vector Machine (SVM) classifier.

---

## Live Demo

Try the app here:  
https://ai-project-edycekhuusnwvwnotftzqt.streamlit.app/

---

## Features

- Predicts diabetes risk in real-time
- Displays probability of being diabetic vs non-diabetic
- Risk level classification (Low / Moderate / High)
- Interactive medical input sliders
- Visual risk gauge chart
- Risk factor analysis
- Health recommendations
- Clean and responsive UI

---

## Machine Learning Model

- Algorithm: Support Vector Machine (SVM)
- Preprocessing: StandardScaler normalization
- Output: Binary classification (Diabetic / Non-Diabetic)
- Probability estimation enabled (probability=True)
